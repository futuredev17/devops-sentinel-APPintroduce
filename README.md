## 💡 这是一个什么东西？
`DevOps Sentinel` 是一款专为 IT 运维、全栈开发者打造的全终端极客运维控制台。它让你彻底摆脱厚重的笔记本电脑，仅用一部手机，就能完成绝大多数紧急排障、服务器监控和自动化脚本执行。

## 🔥 核心功能亮点：

*   **📊 资产中枢**：多级分类管理宿主机、虚拟机、云服务器。支持真实 SSH 连接池，实时查看 CPU/MEM/DISK 状态。
*   **⌨️ HoloLink 极客键盘**：专门为终端设计的悬浮键盘！带光标触摸板、强制锁死英文输入，完美适配手机端敲代码。
*   **⚡ 159 条 Root 级指令库**：涵盖防火墙放行、端口映射、磁盘清理、K8s 节点排水等 15 个高频场景，一键下发执行。
*   **🤖 AI 排障引擎**：支持接入您自己的大模型 API（BYOK），一键分析报错日志并给出修复命令。
*   **🖥️ 局域网赛博大屏**：手机一键生成二维码，平板/电脑浏览器扫码即可实时查看监控数据流。
*   **🔒 极致隐私**：纯本地存储，系统级 Keychain/Keystore 凭证隔离，绝不上传任何业务数据。
